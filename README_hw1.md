# ДЗ1 · Свежие вопросы и агент с поиском

Тезис курса: хороший агент на дешёвой модели обходится дешевле сильной модели в одиночку при том же качестве. Здесь проверяем его на событиях 2025–2026, которых нет в обучающих данных.

## Датасет

Файл: [`data/fresh.jsonl`](data/fresh.jsonl) — **147** вопросов.

- База: стартовый набор семинара (`fresh_2026.jsonl`, 125 вопросов) — факты из обзорных статей английской Википедии про 2026 год.
- Свои **+22** вопроса: спорт, искусство, шахматы, анимация. Источники — открытые страницы Wikipedia (`2026 in sports`, `2026 in art`, `2026 in chess`, …).
- `fresh-134`, `fresh-135`, `fresh-136` — исходы уже прошедших событий (победитель Super Bowl LX, United Bowl, World Baseball Classic), не заранее назначенные площадки.

Требования к записи: событие после 01.01.2025, короткий однозначный ответ, ответ дословно в `evidence`, вопрос самодостаточен.

## Агент

Код: [`agent.py`](agent.py).

Инструменты:

| Инструмент | Что делает |
|---|---|
| `web_search` | поиск по en.wikipedia + intro статьи (`explaintext` / `exintro`) |
| `page_find` | полный текст статьи, строки с keywords |
| `tavily_search` | живой веб (бонус) |
| `calculator`, `python_exec` | с семинара |

У каждого инструмента тесты на 3 случая:

```bash
python agent.py --test-tools
```

Проверка ответа: после нормализации все слова эталона есть в ответе, порядок не важен. Слова-числа от zero до twelve становятся цифрами, поэтому эталон «Twelve» совпадает с «12 people killed». Для дат по-прежнему допускается перестановка «15 March» и «March 15».

### Бонусы

1. **Tavily.** На тех же 147 вопросах wiki+page_find даёт 61%, с Tavily — 77%, и цена задачи падает с $0.00056 до $0.00045: второй источник и помогает, и сокращает число шагов.
2. **Каскад.** Уверенность mini оценивается вместе с найденными строками инструментов. Наверх ушло **10 из 147** (7%). Во всех десяти Sonnet без инструментов ответил «Unknown» и затёр ответ агента, поэтому каскад 71% хуже лучшей дешёвой строки 77%. Эскалация к сильной модели без тех же инструментов по-прежнему портит свежие факты; с уликами в промпте это хотя бы редкий случай, а не 48 из 60.

## Два разобранных провала

Лучший прогон: `traces/дешёвая, поиск+чтение+tavily/gpt-4o-mini/`.

1. [`fresh-4.json`](traces/дешёвая,%20поиск+чтение+tavily/gpt-4o-mini/fresh-4.json) — эталон «A total fire ban» (Victoria, январь 2026). Агент ответил про бесплатный транспорт для несовершеннолетних. **Поиск нашёл не ту меру.**
2. [`fresh-2.json`](traces/дешёвая,%20поиск+чтение+tavily/gpt-4o-mini/fresh-2.json) — эталон «Miguel Díaz-Canel». Агент ответил, что в переговоры с администрацией Трампа вступил Иран. **Поиск нашёл не того человека.**

## Вывод по тезису курса

На полном наборе тезис **подтверждается**:

- сильная модель без инструментов: **1%**;
- дешёвая без инструментов: **0%**;
- дешёвая + поиск + чтение + Tavily: **77%** при $0.00045 за вопрос;
- средняя модель с теми же инструментами: **79%**, но в ~16 раз дороже за вопрос ($0.00729) и в ~16 раз дороже за верный ответ.

Каскад «mini с уликами → голый Sonnet» качество не добавляет: 10 эскалаций все кончились отказом сильной модели.
