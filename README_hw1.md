# ДЗ1 · Свежие вопросы и агент с поиском

Тезис курса: хороший агент на дешёвой модели обходится дешевле сильной модели в одиночку при том же качестве. Здесь проверяем его на событиях 2025–2026, которых нет в обучающих данных.

## Датасет

Файл: [`data/fresh.jsonl`](data/fresh.jsonl) — **147** вопросов.

- База: стартовый набор семинара (`fresh_2026.jsonl`, 125 вопросов) — факты из обзорных статей английской Википедии про 2026 год.
- Свои **+22** вопроса: спорт (гольфисты Masters/PGA/US Open 2026), искусство (Pritzker, Rembrandt в Rijksmuseum), шахматы (GCT 2026), анимация/комиксы. Источники — открытые страницы Wikipedia (`2026 in sports`, `2026 in art`, `2026 in chess`, …).

Требования к записи: событие после 01.01.2025, короткий однозначный ответ, ответ дословно в `evidence`, вопрос самодостаточен.

### Проверка свежести

## Агент

Код: [`agent.py`](agent.py).

Инструменты:

| Инструмент | Что делает |
|---|---|
| `web_search` | поиск по en.wikipedia + intro статьи (`explaintext` / `exintro`) |
| `page_find` | полный текст статьи, строки с keywords |
| `tavily_search` | живой веб (бонус) |
| `calculator`, `python_exec` | с семинара |

У каждого инструмента тесты на 3 случая:

```bash
python agent.py --test-tools
```

Проверка ответа: нормализованный эталон ⊆ ответ; дополнительно допускаем перестановку даты (`15 March` ↔ `March 15`) — описано в `is_correct`.

## Замер

Подвыборка **n=60** (38 из старта + 22 своих), чтобы уложиться в бюджет. Итоговый прогон: **~$0.85**.

```bash
python agent.py --eval --limit 60
```

### Бонусы

1. **Tavily.** Сравнение wiki+page_find (63%) vs +tavily (73%) при меньшей цене задачи: второй источник помогает и сокращает число шагов.
2. **Каскад.** Агент на mini, при низкой confidence — Sonnet *без инструментов*. На свежих фактах это **ломает** результат (8%): сильная модель не знает ответ и перезаписывает уже найденный агентом. Полезный отрицательный результат: каскад имеет смысл, когда верхняя модель сильнее на том же типе задач; здесь сила — в инструментах, не в параметрах.

## Два разобранных провала

Лучший прогон: `traces/дешёвая, поиск+чтение+tavily/gpt-4o-mini/`.

1. [`fresh-4.json`](traces/дешёвая,%20поиск+чтение+tavily/gpt-4o-mini/fresh-4.json) — эталон «A total fire ban» (Victoria, январь 2026). Tavily и `page_find` ушли в другие законы Виктории; модель ответила про remote work / child safety. **Поиск нашёл не то.**
2. [`fresh-3.json`](traces/дешёвая,%20поиск+чтение+tavily/gpt-4o-mini/fresh-3.json) — эталон «a strategic partnership agreement». `page_find` вернул нужную строку про Ukraine–Romania, но в `FINAL` модель перефразировала («Strategic partnership in defense…»), и substring-проверка не прошла. **Ответ по смыслу верный, но не прошёл проверку.**

## Вывод по тезису курса

На этом наборе тезис **подтверждается**:

- сильная модель без инструментов: **0%** — одна дорогая «память» бесполезна на 2026;
- дешёвая без инструментов: тоже **0%**;
- дешёвая + поиск + чтение (+ Tavily): **73%** при ~$0.0005/задачу;
- средняя модель с теми же инструментами: те же **73%**, но в ~20 раз дороже.

Где тезис не про каскад «mini→sonnet без инструментов»: на свежих событиях эскалация к сильной модели без инструментов ухудшает качество. Каскад стоило бы строить как «слабый агент → сильный агент с теми же инструментами», а не «агент → голый Sonnet».

```bash

```
