# ДЗ3 · Фреймворк, критик, голосование, план

Третья неделя: надстройки над циклом агента. Берём голый ReAct из [ДЗ1](README_hw1.md), переносим на LangGraph, добавляем критик с опорой, голосование/каскад и план, и смотрим в центах, что окупилось.

Набор: первые **40** вопросов из [`data/fresh.jsonl`](data/fresh.jsonl). Модель дешёвая — `openai/gpt-4o-mini`, сильная — `anthropic/claude-sonnet-4.6`. Инструменты те же, что в ДЗ1, без Tavily: `web_search` и `page_find`. Все вызовы модели идут через один `httpx.Client` с крючком на ответ; цена — поле `usage.cost` OpenRouter.

Полный прогон: **$1.21**.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # OPENROUTER_API_KEY

python hw3.py --eval --limit 40
```

Ноутбук [`hw3.ipynb`](hw3.ipynb) читает артефакты из `artifacts_hw3/` и не гоняет агента заново.

## Налог фреймворка на пустом запросе

Вопрос `What is 2 + 2? Reply with the number only.`

| исполнение | токенов первого запроса | вызовов | центов |
|---|---:|---:|---:|
| голый цикл | 176 | 1 | 0.0028 |
| LangGraph (с `args_schema`) | 176 | 1 | 0.0028 |
| smolagents, инструменты | 1125 | 1 | 0.0177 |
| smolagents, код | 2132 | 1 | 0.0331 |

На полном наборе первый запрос голого цикла — **181** токен, LangGraph «как есть» — **149**, patched LangGraph — **181**. Разница байт в байт: `tool(page_find)` без `args_schema` отдал схеме поля `title`/`keywords` **без описаний**. Подсказка «exact article title, e.g. 2026 in Japan» пропала. После Pydantic-схемы описания вернулись, и первый запрос совпал с циклом.

LangGraph «как есть» ещё и не делает последний шаг без инструментов: на 13 из 40 вопросов граф упал с `GraphRecursionError` и выбросил найденное. Это чинится middleware `last_step_without_tools`.

smolagents на пустом вопросе дороже в **6–12 раз**: в системный промпт библиотека кладёт длинную инструкцию (у CodeAgent инструменты вообще уходят в текст, не в `tools`).

Одна фраза: сам ReAct-цикл LangGraph этих токенов не стоит — качество patched-версии 23/40 против 26/40 у голого цикла; стоят middleware (последний шаг, потолок вызовов, HITL), которых в цикле нет.

## Критик

Граф `answer → critic → (answer | END)`, не больше двух попыток. Критик судит по тексту инструментов, вердикт — `Verdict` через `with_structured_output`.

Относительно LangGraph без критика: **исправил 2, испортил 1** (нетто +1, 23/40 → 24/40).

- исправил `fresh-15`: «Mykhailo Fedorov» → «Oleksandr Syrskyi»;
- исправил `fresh-21`: отказ → «Gavin Snider»;
- испортил `fresh-24`: верное «a drought» заменил на «crisis management arrangements».

Цена вопроса выросла с 0.034 до 0.061 цента.

## Голосование и каскад

Три независимых прогона LangGraph при `temperature=0.7`. Согласие — набор нормализованных слов (`15 March` = `March 15`). Полное согласие — ответ, иначе тот же агент на Sonnet.

Ушло наверх: **26 из 40** (согласие всех трёх было на 14 вопросах).

| | доля | центов/вопрос | центов за верный |
|---|---:|---:|---:|
| голосование 3 | 0.650 | 0.1009 | 0.1553 |
| каскад | 0.725 | 1.2110 | 1.6703 |
| Sonnet на всём наборе | 0.750 | 1.5836 | 2.1114 |

Голосование без эскалации дало те же 26/40, что голый цикл, втрое дороже. Каскад догнал почти всю сильную модель (29 vs 30) и дешевле её на 0.37 цента вопроса.

## План

Отдельный вызов mini пишет план, план дописывается в системный промпт исполнителя. Доля верных **упала** с 0.575 до 0.400: план отправляет агента не туда, на свежих фактах 2026 он не знает, что искать.

## Проверка проверки

Десять ответов, которые `is_correct` счёл неверными, для каждой сомнительной конфигурации. Проверка — множество слов эталона после нормализации плюс перестановка даты. Поправили до прогона: `March 15` при эталоне `15 March` больше не ошибка.

Из десяти «ошибок» голого цикла и LangGraph:

- **1 эталон устарел на всех конфигурациях одинаково:** `fresh-29`, крушение у Adamuz. Эталон «43», Википедия сейчас пишет «46» — как на семинаре. Модели отвечают 46, проверка пишет «неверно». Эталон не трогали.
- Ещё два похожих расхождения с текущей Википедией: `fresh-6` (4500 vs 519 пропавших в Тибете), `fresh-36` (129 vs 136 погибших на Флоресе). Тоже не чинили золото.
- Остальные из десяти — настоящие промахи поиска (Иран вместо Díaz-Canel) или отказы «не нашёл». Ложных срабатываний проверки на перефразе в этой десятке не было.

Итого: из 10 «неверных» LangGraph **1 точно верный по текущей Википедии, 2 спорны из‑за обновления статьи, 7 настоящие ошибки**.

## Потолок на деньги

`ModelCallLimitMiddleware(run_limit=2, exit_behavior="end")` — ограничение кодом, не промптом.

Вопрос: «Compare the months of the 2026 Winter Olympics and the 2026 FIFA World Cup, then list three events of each.»

После обрыва агент ответил: `Model call limits exceeded: run limit (2/2)`. Счётчик зафиксировал **2** вызова модели.

## Человек в контуре

Необратимый инструмент `send_summary` + `HumanInTheLoopMiddleware`. Вопрос: найти победителя финала ЧМ-2026 и отправить письмо.

1. Граф остановился перед `send_summary` (текст «Spain won…»).
2. Отказ с комментарием «Добавь в письмо счёт финала» — агент переписал текст (добавил 2-0) и снова запросил подтверждение.
3. Одобрение — письмо «отправлено», ответ: агент нашёл победителя и отправил сводку.

## Две строки выводов

Прирост дал каскад по согласию: 26/40 голосов mini → 29/40 после Sonnet на 26 разногласиях, почти линия сильной модели (30/40) и дешевле её. Критик с опорой — слабый плюс (исправил 2, испортил 1).

Дорогое украшение: план (16/40), голосование без эскалации (те же 26/40, что голый цикл, втрое дороже) и LangGraph «как есть» (13 падений по рекурсии). Patched-фреймворк на качестве не окупился: 23/40 против 26/40 у цикла при той же цене вопроса; его цена оправдана только middleware (потолок и HITL).
